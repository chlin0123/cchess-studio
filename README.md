# 象棋打譜系統 Pro

一個**純前端**的象棋打譜與人機對弈系統。不需要安裝、不需要伺服器、不需要建置，用瀏覽器打開 `index.html` 就能玩。AI 運算全部在使用者自己的瀏覽器內執行。

🌐 線上版（需在 GitHub 啟用 Pages）：https://chlin0123.github.io/cchess-studio/

---

## 功能特色

### ♟️ 打譜
- 點擊棋子即顯示合法落點，完整實作象棋規則（蹩馬腿、塞象眼、炮架、將帥不可照面、不可送將等）
- 棋譜列表點選任一步即可跳轉，支援 `←` / `→` 鍵逐步瀏覽
- 每一步都可寫註解講解
- 悔棋、翻轉棋盤、新局復原

### 📚 內建 9 局經典古譜與名局
《橘中秘》、《梅花譜》、近代定式與宗師名局（共 119 步）。每次開啟頁面都會自動用規則引擎驗證全部棋步。

### 🤖 五位 AI 對手

| 等級 | 棋手 | 稱號 | 搜尋深度 | 風格 |
| :--- | :--- | :--- | :--- | :--- |
| Lv.1 | 林小軒 | 街頭棋童 | 5 層 | 快攻飛刀，偶爾忽略後防 |
| Lv.2 | 陳鐵山 | 公園擂台主 | 8 層 | 屏風馬與馬炮殘局，棄子搶攻 |
| Lv.3 | 沈滄海 | 省冠國手 | 12 層 | 雙車出動快，陣型厚實 |
| Lv.4 | 顧千帆 | 特級宗師 | 14 層 | 擅長臥槽馬、鐵門栓與悶宮殺 |
| Lv.5 | 天璣玄極 | 深算棋神 | 16 層 | 極限深算 |

- 可選擇**電腦執黑**（預設）、**電腦執紅**或**雙人打譜**
- **AI 支招**：分析目前盤面並標示建議著法，再按一次可直接代走
- **背景預思考**：輪到玩家思考時，AI 會在背景靜默推演，不顯示任何預測，也不影響畫面操作

### 💾 存檔
- **終局自動存檔**：分出勝負時自動存入棋譜庫，名稱標記勝負、對手與時間，例如 `[自動][負] Lv.4顧千帆 2026-11-01 17:45:21`
- 自動存檔最多保留 100 盤，超過時刪除最舊的自動存檔；**手動存檔不會被刪除**
- **手動存檔**、刪除存檔
- **匯出 / 載入**：以 JSON 格式複製或貼上棋譜，方便分享

> [!NOTE]
> 存檔放在瀏覽器的 `localStorage`（鍵名 `XIANGQI_SAVED_GAMES_V2`），只存在**使用者自己的瀏覽器**裡。換瀏覽器、換電腦或清除瀏覽資料後就看不到了，重要棋譜請用「匯出」備份。

## 使用方式

### 本機
直接用瀏覽器（Chrome、Edge、Firefox、Safari）打開 `index.html` 即可。

### 上線發布（GitHub Pages）
1. 到儲存庫的 **Settings → Pages**
2. **Source** 選 `Deploy from a branch`，**Branch** 選 `main`、資料夾選 `/ (root)`，按 **Save**
3. 約 1 分鐘後即可透過 `https://<帳號>.github.io/cchess-studio/` 遊玩，之後每次推送到 `main` 都會自動更新

因為是純靜態網頁，也可以直接部署到 Cloudflare Pages、Vercel、Netlify 等平台，不需要建置指令。

## 棋譜 JSON 格式

```json
{
  "title": "棋譜名稱",
  "steps": [
    { "f": [7, 7], "t": [7, 4], "c": "炮二平五" },
    { "f": [0, 1], "t": [2, 2], "c": "馬２進３" }
  ]
}
```

- `f` / `t`：起點 / 終點座標 `[列, 行]`，列 `0–9`（0 為黑方底線），行 `0–8`
- `c`：該步註解（選填，最多 2000 字）
- 載入時會逐步驗證規則，任何一步不合法就整份退回，不會破壞目前的棋局

## AI 引擎技術概要

- Negamax + Alpha-Beta + 主要變例搜尋（PVS），迭代加深
- Zobrist 雜湊置換表（524,288 筆）
- 空著裁剪（Null-Move Pruning）、後段著法減深（LMR）；**將軍著法不減深**並觸發將軍延伸
- 靜態搜尋（Quiescence Search）處理吃子交換
- 殺手著法與歷史啟發排序，臥槽馬／掛角馬等叫將威脅優先搜尋
- 局面評估：子力位置表、九宮氣數、窩心馬與塞將門懲罰、空頭炮／鎮中炮、車線開通、孤炮過河懲罰等
- 開局庫（含左右鏡像）
- 背景預思考在 Web Worker 中以時間切片執行，隨時可被新的思考指令打斷

## 安全性

- 全程使用 `textContent` / `replaceChildren()` 更新畫面，**不使用** `innerHTML`、`eval`、`Function` 等，避免 XSS
- 內容安全政策（CSP）只允許載入同站的腳本與樣式，禁止內嵌腳本、內嵌事件處理器與任何網路連線
- AI Worker 只接受固定格式的訊息並驗證棋盤；AI 回傳的著法在主畫面套用前會再次驗證是否合法
- 載入棋譜時檢查座標範圍、步數上限（500 步）並逐步驗證規則，失敗時完整還原
- 讀取 `localStorage` 時過濾 `__proto__`、`constructor`、`prototype` 等保留鍵，防止原型污染
- 不收集任何使用者資料，也沒有任何網路請求

## 專案結構

```
cchess-studio/
├── index.html      # 頁面結構（含內容安全政策 CSP）
├── css/style.css   # 樣式
├── js/engine.js    # 規則與 AI 引擎（不碰 DOM，可在 Web Worker 中執行）
├── js/app.js       # 介面、對局流程、存檔、AI Worker 管理
└── README.md
```

AI 搜尋與背景預思考在 **Web Worker** 中執行，思考時畫面不會卡住；若瀏覽器無法建立 Worker，會自動改在主執行緒運算。直接雙擊 `index.html`（`file://`）也能正常使用。
